# E-Commerce Shipping Analysis Using R
**Logistics performance analysis identifying delivery efficiency factors**

## 🎯 Business Context
Analysis of e-commerce shipping dataset (10,999 records) to understand factors affecting delivery performance, customer satisfaction, and operational efficiency in logistics operations.

## 📊 Dataset Overview
- **Records:** 10,999 shipping transactions
- **Features:** 12 variables including delivery times, customer ratings, shipping modes
- **Scope:** Comprehensive e-commerce logistics data covering multiple operational aspects

## 🔍 Analysis Framework
**Data Preprocessing:**
- Missing value handling and data type standardization
- Feature engineering for delivery performance metrics
- Data cleaning and consistency checks

**Exploratory Analysis:**
- Delivery time trend analysis across shipping methods
- Customer satisfaction pattern identification
- Operational efficiency factor analysis
- Statistical relationship exploration between logistics variables

**Insight Generation:**
- Key factor identification for shipping delays
- Customer rating correlation with delivery performance
- Operational recommendations based on data patterns

## 🛠️ Technical Stack
**Language:** R  
**Core Libraries:** dplyr (data manipulation), ggplot2 (visualization), tidyr (data tidying)  
**Environment:** RStudio  
**Techniques:** Statistical analysis, data visualization, logistics performance metrics

## 📈 Analysis Components
- **Delivery Performance:** Time-based analysis of shipping efficiency
- **Customer Satisfaction:** Rating patterns and correlation analysis
- **Operational Factors:** Variable impact on logistics outcomes
- **Visual Analytics:** Comprehensive charts showing logistics patterns

## 🎓 Skills Demonstrated
- R programming for business analytics
- Logistics data analysis techniques
- Statistical visualization with ggplot2
- Supply chain performance evaluation
- Data-driven operational insights
