# E-Commerce-Shipping-Data-Analysis-Using-R

---

## 🎯 Objective

Analyze an E-Commerce Shipping dataset to identify factors affecting delivery, customer satisfaction, and operational efficiency. Provide actionable insights to optimize logistics and supply chain management.

---

## 🛠️ Tools & Techniques Used

- **Language:** R  
- **Libraries:** dplyr, ggplot2, tidyr  
- **Dataset:** 10,999 records, 12 features (E-Commerce Shipping Dataset)  
- **Techniques:** Data preprocessing, EDA, feature engineering, visualization

---

## 📋 Summary of Work Done

- Imported and cleaned data: handled missing values and formatted variables.  
- Performed exploratory data analysis with descriptive stats and graphs.  
- Engineered new features for delivery time trends and customer satisfaction.  
- Identified key factors influencing shipment delays and customer ratings.  
- Developed recommendations to improve shipping efficiency and customer experience.

---

## 🔍 Methodology

- **Data Cleaning:** Removed inconsistencies, imputed missing data, converted data types.  
- **Exploratory Analysis:** Used correlation, histograms, and box plots to detect patterns.  
- **Feature Transformation:** Encoded categorical variables, created derived features.  
- **Insights:** Derived actionable recommendations to reduce delays and optimize logistics.

---

## 💡 Insights & Impact

This project demonstrates how data-driven approaches enhance e-commerce shipping logistics by identifying delay causes and satisfaction drivers, helping improve operational efficiency.
